Install LabaLab Robot Hub

For Windows 10 and 11. Takes about two minutes. You do not need Python, Git or anything else.

1
Open PowerShell.

Press the Start button, type PowerShell, and press Enter.

2
Paste this line and press Enter.
irm https://github.com/labbgulab-lab/robot-hub/releases/latest/download/install.ps1 | iex
3
That's it.

The hub opens by itself. Next time, double-click LabaLab Robot Hub on your desktop. To update, run the same line again.
