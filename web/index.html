1. Set up your phone's hotspot

  • iPhone: Settings → Personal Hotspot → Allow Others to Join on, and Maximize Compatibility on (that is what makes it 2.4 GHz). Keep that screen open while a robot joins: an iPhone hides its hotspot from new devices otherwise.
  • Android: Hotspot settings → AP band / Wi-Fi band → 2.4 GHz.
  • Use a plain name, only letters, digits and spaces. The iPhone's default “Name’s iPhone” has a curly apostrophe that the Reachy app shows as “?”. Rename it in Settings → General → About → Name.
  • Connect this laptop to the hotspot too, then press Check again. Switch off auto-join for other WiFi (e.g. campus), or the laptop will wander off mid-session.
  • Tip: robots remember a network by its name and password. If everyone gives their hotspot the same name and password, every robot that joined one already knows them all.

2. Teach each robot your hotspot (once per robot)

After this the robot rejoins by itself whenever the hotspot is on. Turn the hotspot on before powering a robot.

Reachy Mini
  1. Already on a hotspot it knows? Launch it, then on its dashboard press Add WiFi…, type your hotspot's name and password, and Save. It stays where it is; turn the old hotspot off and yours on, and it moves over by itself.
  2. Otherwise power it on. If it knows no network nearby, it opens its own WiFi called reachy-mini-ap.
  3. Open the Reachy Mini Control desktop app. It joins reachy-mini-ap (or uses Bluetooth) and asks for the WiFi to use. Pick your hotspot and type its password.
  4. The robot restarts its WiFi and appears on your hotspot within a minute. Its card here lights up. If the app offers a software update, let it finish.
NAO
  1. Already on a hotspot it knows? Turn your hotspot on next to it, then on NAO's card press Add WiFi…, type its name and password, and Join. NAO moves to it now and remembers it. Connect this laptop to your hotspot to see NAO again.
  2. Otherwise:
  3. Connect NAO with an Ethernet cable to the laptop (or to a network it already knows), and power it on.
  4. Press the chest button once: NAO says its address. Open http://nao.local/ (or that address) and sign in as nao / nao.
  5. Network settings → WiFi → choose your hotspot → enter the password → Connect. NAO saves it and rejoins on every boot. Unplug the cable.
  6. If the web page won't connect: SSH in as nao, run connmanctl, then agent on, scan wifi, services, connect wifi_…_managed_psk (your hotspot's line) and type the password.
Furhat
  1. Turn the hotspot on first: Furhat only looks for WiFi while it boots.
  2. On Furhat's own screen (plug in a keyboard) → WiFi settings → choose your hotspot → password. It remembers it.
  3. Power-cycle Furhat with the hotspot on. The hub finds it by itself (Furhat has no network name to look up).
Pepper
  1. Already on a hotspot it knows? Same as NAO: Add WiFi… on Pepper's card, with your hotspot on.
  2. Otherwise, on Pepper's tablet: six-dot menu → Settings → Wi-Fi → choose your hotspot → password. Don't use “Advanced Settings” for WiFi, or the head and the tablet end up on different networks.

3. Check

A robot that has joined appears as a card below within a few seconds, and its address starts with the same numbers as this laptop's. Not there? Press Scan now, check the hotspot is still on 2.4 GHz, and power-cycle the robot with the hotspot on.
