# Robot guides

Step-by-step slides for every robot in the LabaLab (room −132). Start with the
lab guide, then open the guide for the robot you are using.

| Guide | What it covers |
|---|---|
| [Lab robots guide](Lab-robots-guide.pdf) | The rules, installing Robot Hub, a session from start to end, every robot in short, WiFi and phone hotspots, fixing problems |
| [Reachy Mini guide](Reachy-Mini-guide.pdf) | The wireless Reachy and the USB Lite, Talk, characters, group conversations, Wizard of Oz |
| [Furhat guide](Furhat-guide.pdf) | Starting Furhat, Studio and its settings, the chat skill, and writing your own skill in Kotlin |
| [Pepper guide](Pepper-guide.pdf) | Safety and the chest button, the tablet, the dashboard, the demo, Wizard of Oz |
| [NAO guide](NAO-guide.pdf) | The chest button, WiFi, the posture buttons, the NAO app and a research session |

Stuck? In Robot Hub open **Logs › Save a report for the lab** and send it to
lab staff. Keys are removed from the report for you.
